# PetraPMS — Quick start (15 minutes)

1. **Install** — double-click `PetraPMS-Setup-1.0.0.exe`, accept the administrator prompt, click Next → Install.
2. **Choose how this computer is used** (first launch): *Single computer* is right for most small hotels.
3. **Quick setup wizard** — hotel name & BIN → floors and room numbers → room types & base rates → VAT 15% / service charge 10% → administrator password → *Create my hotel*. Tick *Load demo data* if you want to explore first (clear it later in **Data center → Demo data**).
4. **Sign in** with the administrator you just created. Press **Ctrl+K** to search anything.
5. **First booking** — *New reservation* → pick/create guest → dates → room type → *Create*. On arrival day: **Front desk → Check in**.
6. **Take payment & check out** — open the guest's folio → *Take payment* → **Front desk → Check out** → print invoice.
7. **Every night** — **Night audit → Run audit** (posts room + tax charges, rolls the business date).
8. **Backups** — **Data center → Backup**: set a folder on another disk/USB. A backup is also taken automatically before every night audit.

Already have guests or bookings in Excel? **Data center → Import** (download the template, fill it, upload, *Check*, *Import*; undo for 24 h).
